GitHub verwendet dafür standardmäßig die Syntax von MathJax (für Mathematik) und Mermaid (für Diagramme). Sie müssen keine externen Plugins oder Bilder einfügen, sondern können den Code direkt in Ihre Markdown-Datei (.md) schreiben.
Hier ist eine Übersicht, wie Sie beide Funktionen nutzen:
1. Mathematische Formeln (MathJax)
Sie können mathematische Symbole und Gleichungen entweder direkt im Text (Inline) oder als separaten Block anzeigen lassen. Nutzen Sie dafür das $-Zeichen.

    Inline-Mathe: Setzen Sie die Formel zwischen zwei einzelne $-Zeichen.
        Code: Die Formel lautet $E = mc^2$.
    Block-Mathe: Setzen Sie die Formel in eine eigene Zeile zwischen jeweils zwei $$-Zeichen.
        Code:
        markdown

        $$
        \frac{a}{b} = c
        $$


2. Flussdiagramme (Mermaid)
Um Diagramme zu erstellen, nutzen Sie einen normalen Code-Block (drei Backticks ```), schreiben aber das Wort mermaid als Sprachbezeichner direkt dahinter.
Hier ist ein einfaches Beispiel für ein Flussdiagramm (Flowchart):
markdown

```mermaid
graph TD
    A[Start] --> B{Ist es GitHub?}
    B -- Ja --> C[Mathe & Diagramme funktionieren!]
    B -- Nein --> D[Anderen Editor nutzen]
```

Kurze Übersicht der Mermaid-Grundlagen:

    graph TD: Definiert die Richtung von oben nach unten (Top-Down). Nutzen Sie graph LR für eine Darstellung von links nach rechts (Left-Right).
    -->: Erstellt einen einfachen Pfeil zwischen zwei Knoten.
    Formen der Knoten:
        Eckige Klammern A[Text] = Rechteck
        Geschweifte Klammern B{Text} = Raute (für Entscheidungen)
