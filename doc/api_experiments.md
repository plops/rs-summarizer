# Gemini & Gemma API Experiments: Grounding, URL Context, and Thinking

This document reports the experiments conducted on June 13, 2026, to verify and understand the `gemini-rust` (v1.7.1) APIs for:
1. **Google Search Grounding** (Gemini and Gemma models)
2. **URL Context** (Gemini models)
3. **Thinking Mode and Thoughts Extraction** (Gemini models)

## 1. Example Code Used in Experiments

Below are the exact test programs written and executed during validation.

### A. Grounding & URL Context Test (`test_api.rs`)
```rust
use gemini_rust::{Gemini, Model, Tool};
use std::fs;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_key = fs::read_to_string("/home/kiel/api_key.txt")?.trim().to_string();
    let client = Gemini::with_model(&api_key, Model::Custom("models/gemini-2.5-flash".to_string()))?;

    // 1. Google Search Grounding
    println!("--- Testing Google Search Grounding ---");
    let response = client
        .generate_content()
        .with_user_message("What was the result of the latest Formula 1 Grand Prix?")
        .with_tool(Tool::google_search())
        .execute()
        .await?;

    println!("Response:\n{}\n", response.text());
    
    if let Some(candidate) = response.candidates.first() {
        if let Some(metadata) = &candidate.grounding_metadata {
            println!("Grounding Metadata found!");
            if let Some(queries) = &metadata.web_search_queries {
                println!("Search Queries: {:?}", queries);
            }
            if let Some(chunks) = &metadata.grounding_chunks {
                println!("Sources:");
                for chunk in chunks {
                    if let Some(web) = &chunk.web {
                        println!(" - [{}]({})", web.title, web.uri);
                    }
                }
            }
        }
    }

    // 2. URL Context
    println!("\n--- Testing URL Context ---");
    let response_url = client
        .generate_content()
        .with_user_message("Summarize key information from this webpage: https://rocketrecap.com/browse")
        .with_tool(Tool::url_context())
        .execute()
        .await?;

    println!("Response:\n{}\n", response_url.text());
    Ok(())
}
```

### B. Thinking Mode Test (`test_thinking.rs`)
```rust
use gemini_rust::{Gemini, Model};
use std::fs;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_key = fs::read_to_string("/home/kiel/api_key.txt")?.trim().to_string();
    let client = Gemini::with_model(&api_key, Model::Custom("models/gemini-2.5-flash".to_string()))?;

    println!("--- Testing Gemini Thinking Mode ---");
    let response = client
        .generate_content()
        .with_user_message("Solve this puzzle: A man is looking at a photograph. His friend asks, 'Who is it?' The man replies, 'Brothers and sisters I have none, but this man's father is my father's son.' Who is in the photograph?")
        .with_dynamic_thinking()
        .with_thoughts_included(true)
        .execute()
        .await?;

    // Print thoughts
    let thoughts = response.thoughts();
    println!("--- Model's Thinking Process ({:?} tokens used for thoughts) ---", 
        response.usage_metadata.as_ref().and_then(|m| m.thoughts_token_count)
    );
    for (i, thought) in thoughts.iter().enumerate() {
        println!("[Thought {}]\n{}", i + 1, thought);
    }

    println!("\n--- Final Response ---");
    println!("{}", response.text());
    Ok(())
}
```

## 3. How to Use & Integrate These Features in Rust

### A. How to Separate Thoughts (for Gemini)
For Gemini models supporting reasoning, enable thoughts inside `ThinkingConfig` and query them from the returned candidates:

```rust
// 1. Enable thoughts in the request
let response = client
    .generate_content()
    .with_user_message("Prompt here...")
    .with_dynamic_thinking() // Or .with_thinking_level(ThinkingLevel::High)
    .with_thoughts_included(true)
    .execute()
    .await?;

// 2. Separate thoughts from final response text
let thoughts: Vec<String> = response.thoughts(); // Reasoning process blocks
let final_summary: String = response.text();     // Final text response

// 3. Extract tokens used for reasoning
let thinking_tokens = response.usage_metadata
    .as_ref()
    .and_then(|m| m.thoughts_token_count)
    .unwrap_or(0);
```

### B. How to Use URL Context (for Gemini)
Add the `Tool::url_context()` to the request to allow the model to crawl URLs supplied in the prompt:

```rust
let response = client
    .generate_content()
    .with_user_message("Summarize: https://example.com")
    .with_tool(Tool::url_context())
    .execute()
    .await?;
```

### C. How to Use Google Search (for Gemini and Gemma)
Add the `Tool::google_search()` to the request to search the web for grounding information:

```rust
let response = client
    .generate_content()
    .with_user_message("What is the current stock price of Google?")
    .with_tool(Tool::google_search())
    .execute()
    .await?;

// Retrieve search citations from grounding metadata
if let Some(candidate) = response.candidates.first() {
    if let Some(metadata) = &candidate.grounding_metadata {
        let queries = &metadata.web_search_queries; // Queries executed
        let chunks = &metadata.grounding_chunks;     // List of sources used
    }
}
```
